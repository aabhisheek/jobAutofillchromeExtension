Import from Gmail

Reads the confirmation emails every ATS already sends you and turns them into cards on this board — so Applied this week counts jobs you did not have to remember to track. Read-only access to your mail; nothing is ever sent or deleted.

One-time setup

  1. Open Google Cloud credentials and create an OAuth client of type Chrome Extension. Copy the Client ID (it ends apps.googleusercontent.com).
  2. Paste that Client ID below. It is a public identifier, not a secret — there is nothing to protect and no client secret to store.
  3. In the same Google Cloud project, enable the Gmail API.

From Google Cloud → APIs & Services → Credentials. Either client type works, and they are configured differently:

  • Chrome Extension — put your extension ID above in Application ID. No secret; leave the field below empty.
  • Web application — copy the redirect URI from the box below and add it to Authorized redirect URIs, then paste its client secret into the field underneath. Use the Copy redirect URI button: a missing or extra trailing slash is a redirect_uri_mismatch, and Google treats these as exact strings.

Google’s token endpoint rejects a Web client id with client_secret is missing, so it is sent when set. Stored in this browser only, and never written to the extension’s files. Rotate it in Google Cloud if it has ever been pasted into a public place.

Redirect URI sent to Google

Which Google Cloud field each value goes in:

  • Chrome Extension client → set Application ID to the extension ID. Google derives the redirect URI from it, so there is nothing to paste and no redirect URI to register.
  • Web application client → add the redirect URI to Authorized redirect URIs. Add it as its own row; don’t edit or remove anything already listed, since other installs rely on those entries.

If either one disagrees, connecting fails with Error 400: redirect_uri_mismatch before any consent screen appears. Find your extension ID on chrome://extensions; moving the folder on disk changes an unpacked extension’s ID, which changes both values above.
