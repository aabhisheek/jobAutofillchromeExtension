Tailor Resume for a Job Description

Paste a job description below. The description's role is detected (Data Engineer, AI Engineer, Java Developer, …; falling back to Full Stack Developer) and the resume is rewritten for it — every experience, project and skill reworded, and the timeline rescaled to the years the description asks for, with the graduation year moved to match. Keywords the description uses that match something true in your profile.json (skills, experience, projects) are folded into the skills lineup; keywords with no match in your profile are listed as "Not added" and never inserted. Your resume PDF is the source: its text and structure are read back into LaTeX, previewed here as rendered A4 pages (old vs. new), and written back out as a PDF via "Save as PDF". The PDF this extension already has is picked up automatically — upload another below to replace it. Nothing is uploaded anywhere by this page.

Opened this via the popup's "Tailor Resume for This Job" button? The description below was auto-filled and analyzed from that page already — just double-check it grabbed the right text.

Use a .tex file instead (optional)

Only needed if you have LaTeX source and would rather not go through the PDF. Uploading a PDF above is the normal path; this box takes over as the source when you use it. With neither set, the "current" side is your resume PDF itself — resumePdfPath from settings.json (or the PDF you uploaded above), read and converted to LaTeX automatically.

Rewrite for a target role

Picks a role playbook (Java Developer, AI Full Stack, Cloud Full Stack, Data Engineer, .NET, Go/FinTech, React, Android, Superset, Cybersecurity, Data Analyst, …) and rewrites the headline, summary, job titles, experience bullets, projects and skills to speak that role's language — same companies, same facts. Optionally rescales the employment timeline so total experience equals 1–7 years: durations keep their proportions, "Present" stays anchored to today, and the company order never changes. A pasted job description above is auto-detected to preselect the matching role.
