Your Profile

This is the single source of truth used to fill applications. Edit the JSON directly. Sensitive fields (sponsorship, work authorization, EEO, etc.) live under answers — leave any of them blank to force the extension to flag that question as "unmatched" instead of guessing.

src/data/profile.json is bundled with the extension source and used as the fallback whenever nothing is saved yet (fresh install, cleared storage, etc.) — so you don't re-type your profile after unrelated code changes. Edit here and click Save to update your live copy; click Download to export it back over the file in source control.

AI Draft Answers

Used only for free-text questions your profile can't answer directly (e.g. "Describe a project…"). Never used for sponsorship, work authorization, or EEO questions — those are always taken verbatim from answers above, or left blank for you to fill in.

Groq is tried first. If it fails or no Groq key is set, Gemini is used as a fallback.

src/data/settings.json is bundled with the extension source and used as the fallback whenever no AI settings are saved yet, so keys survive unrelated code changes. It ships in cleartext inside the extension folder — keep it out of version control.

Product Analytics

Sends anonymous usage events to Mixpanel so you can see which ATS platforms autofill actually works on. Counts and platform names only — never a field value, your profile, a job description, a resume, an API key, or the URL of any page you visit. Events are identified by a random per-install id generated locally, and IP geolocation is disabled.

From Mixpanel → Project Settings → Project Token. This is a public, write-only token (the same one a website ships in its page source), so it is safe to commit. Until one is set, events are queued locally and nothing is sent.
